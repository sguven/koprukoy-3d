# Referans fotoğraflar (Köprüköy, Keskin/Kırıkkale — Nisan 2026 Street View)

- 01: Uydu haritası, köy merkezi. Güvendioğlu Market (ana kavşak); "Köprüköy Köyü Yolu"; sağ altta kubbeli cami.
- 02: Eski belediye binası ("T.C. Köprü Belediyesi"), 3 kat, beyaz/kirli badana, kırmızı-kahve kolon şeritleri, geniş pencereler, kiremit saçak. Önünde kaide üzerinde Atatürk heykeli. Solda yeşil çatılı çardak, sağda kahve.

- 04: Bakkal/kahve önü, yeşil alan, bank, çöp kutusu, kaldırımlı asfalt yol.
- 05: Belediye binası ve meydan geniş açı; stabilize toprak meydan, park eden araçlar, arkada minare.
- 06: Cami — açık yeşil/turkuaz badana, kurşun kubbe + küçük kubbeler, tek ince taş minare (şerefeli), kiremit duvarlı avlu, kırmızı sıvalı bahçe duvarı; önde çimen, piknik masası, kaldırım.
